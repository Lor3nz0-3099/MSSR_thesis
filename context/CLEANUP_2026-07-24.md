# Repository cleanup — 2026-07-24

The repository was reduced from approximately 2.2 GB to 1.2 GB.

Removed as reproducible artifacts:

- VS Code IntelliSense database and its WAL/SHM files;
- root and `mssr_ws` colcon `build`, `install` and `log` directories;
- the local `scripts/freebot_docking/.venv`;
- Python `__pycache__`, bytecode and pytest caches;
- generated `UNKNOWN.egg-info`;
- Isaac/NVIDIA shader cache directories.

Preserved deliberately:

- `logs/datasets` and `logs/bridge`, because they contain the spherical
  prototype observations and may be useful as generalization baselines;
- reference PDFs and their source archive;
- CAD source, `OldVersions`, USD assets and the FreeBOT source archive;
- all source code, scenario configurations and experiment documentation.

The `.git` directory is currently empty and is not a valid Git repository.
Material deletions are therefore not recoverable through Git. Large scientific
logs and source archives should only be deleted after an explicit retention or
archive decision.
