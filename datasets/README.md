# MSSR datasets

This directory is the local workspace for datasets generated by the deterministic
MSSR experts and intended for the imitation-learning pipeline.

Dataset payloads are deliberately not versioned in Git because they can be very
large. The current local workspace may contain, for example:

- `expert_v1/`
- `expert_v1_compact/`
- per-episode trajectories and derived training data

The repository versions only this README and the code required to generate,
process and consume the datasets.

Do not use `git add -f` on dataset payloads unless a specific small artifact is
intentionally being added to the repository.
